# Auto-stop timer fix: 0.3.0-beta.3.2

Brief console reconnects and retryable panel outages no longer erase saved idle timers or pending warnings. Shutdown decisions remain paused while player counts or panel access are uncertain. Once a reliable reading returns, an empty server resumes its existing deadline and an occupied server starts a fresh idle window. Explicit monitoring pauses, archival, deletion, and permanent access loss still clear idle history.

## Upgrade

For public Compose installations, set `BRIDGE_VERSION=0.3.0-beta.3.2`, pull the image, and recreate the bot with its existing project and data volume. Legacy installations should retain their Compose files and volume. The version-matched Pterodactyl Egg pins the new image. Auto-stop settings are unchanged and no storage migration is required. Idle history already erased by an earlier version cannot be recovered automatically.

## Validation

Regression tests cover repeated unknown-player readings and retryable panel failures across an overdue deadline, recovery with zero or active players, invalid player counts, and suppression of duplicate stops. Power requests in these tests are mocked. Existing lifecycle tests cover explicit pause and permanent-access reset behavior. Actual Panel/Wings Egg acceptance remains pending; no live game-server shutdown is used to validate this fix.
