# Join hint beta: 0.3.0-beta.3.1

Joining players on Factorio and Minecraft now receive a private, one-sentence hint when chat relay is enabled and a chat channel is linked:

> Start messages with # to send them to the linked chat channel.

Factorio uses `/whisper`; Minecraft uses `/tellraw`. Duplicate joins are suppressed until the player leaves, and console history replayed during reconnects does not send hints. Hints are best-effort and are never queued for later delivery. Factorio names containing whitespace, quotes, or backslashes are skipped because they cannot be safely passed as a single whisper target; Minecraft hints require a standard Java player name.

## Upgrade

For public Compose installations, set `BRIDGE_VERSION=0.3.0-beta.3.1`, pull the image, and recreate the bot while preserving the existing project and data volume. Legacy installations should retain their existing Compose files and volume. For Pterodactyl, use the attached version-matched Egg and pinned image while preserving the server directory. No storage migration is required.

## Validation

Tests cover targeted command construction, live joins, leaves, duplicate suppression, reconnect-history filtering, relay disablement, stale runtimes, and delivery failure handling. Release CI validates the packaged Egg and publishes native amd64 and arm64 images.
