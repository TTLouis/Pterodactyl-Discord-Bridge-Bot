# Feature beta: 0.3.0-beta.3

Chat forwarding now requires a leading `#` in Discord, optional KOOK channels, and supported in-game chat. For example, `#hello everyone` forwards as `hello everyone` to the linked destinations. Messages without the prefix stay local, and `#` alone does not forward an empty message. Only the first `#` is removed, so `##topic` forwards as `#topic`.

The Discord chat relay settings and README explain the new rule. Existing relay enablement and linked channels continue to apply.

## Upgrade

This changes how users send relayed messages. Tell users to start messages intended for linked channels or the game with `#`.

Back up the complete private data volume and deployment settings. For the public Compose installation, set `BRIDGE_VERSION=0.3.0-beta.3`, pull the image, and recreate the bot while preserving its project name and data volume. Legacy installations should retain their existing Compose files and volume. No storage schema change or reinstall is required.

For Pterodactyl, import the attached version-matched Egg and explicitly select the matching pinned image on the existing server. Preserve its server directory. Actual Panel/Wings acceptance remains pending, as in earlier betas.

## Validation

Automated tests cover forwarding in both directions, prefix removal, empty-message rejection, literal-prefix checks before mention normalization, queue behavior, and reconnect-history filtering. Container smoke checks cover setup, persistence, recovery, reinstall, monitoring, SIGINT shutdown, health checks, and backup restoration. Release CI validates the version and publishes native amd64 and arm64 container images.
