# Auto-stop timer fix on main: 0.3.0-beta.3.3

Idle auto-stop retains its saved deadline and pending warning through brief console reconnects and retryable panel outages. Shutdown decisions pause until a reliable player count returns. Empty servers resume the existing deadline; occupied servers start a fresh idle window. Explicit monitoring pauses, archival, deletion, and permanent access loss still clear idle history.

This release publishes the beta.3.2 timer fix from `main`. Application behavior is unchanged from beta.3.2.

## Upgrade

For public Compose installations, set `BRIDGE_VERSION=0.3.0-beta.3.3`, pull the image, and recreate the bot with its existing project and data volume. Legacy installations should retain their Compose files and volume. The version-matched Pterodactyl Egg pins the new image. Auto-stop settings are unchanged and no storage migration is required. Idle history erased by earlier versions cannot be reconstructed automatically.

## Validation

The timer fix passed all 483 Node 24 tests and isolated image installation, restart, health, and storage-recovery checks. DockerVM verification confirmed that settings and saved timers survived startup and a complete live console credential-renewal cycle. Beta.3.3 release CI repeats the full test suite and image checks for both supported architectures. Actual Panel/Wings Egg acceptance remains pending.
