# First public beta: 0.3.0-beta.1

Manage Pterodactyl servers through private Discord administration cards, with live status, supported game chat relays, confirmed power controls, idle auto-stop, and optional KOOK mirroring.

## Install

1. **Pterodactyl:** import the attached Egg, create a dedicated server using its pinned image, and set `DISCORD_TOKEN`. This deployment path is experimental.
2. **Docker Compose:** download and extract the source archive, copy `.env.example` to `.env`, set `DISCORD_TOKEN` and `BRIDGE_VERSION=0.3.0-beta.1`, then run `docker compose -f docker-compose.yml up -d`.
3. **Standalone / Node.js:** download and extract the source archive, install Node.js 24, copy `.env.example` to `.env`, set `DISCORD_TOKEN`, then run `npm ci --omit=dev` and `npm start`.

Enable Message Content Intent and invite your Discord bot with the permissions listed in the README. Once the bridge shows `Bridge ready`, run `/bridge setup` as the guild owner or an administrator. Connect your Panel through the private modal, choose categories and access roles, create a status channel, and discover/import your servers. No `servers.json` is required for a fresh install.

## Included capabilities

- Factorio and Minecraft player lists and chat relay; Satisfactory API player counts; Source 1 console player detection and chat relay.
- Private onboarding, server discovery, per-server settings, confirmed publication, and repair of published channel access.
- Confirmed power actions, idle auto-stop with player-detection safeguards, archive/unarchive, and shared status/channel ordering.
- Persistent settings and credentials, restart recovery, diagnostics, and optional KOOK integration.
- Version-pinned container images for Linux AMD64 and ARM64.

## Beta limitations

Actual Pterodactyl Panel/Wings Egg import and end-to-end acceptance remain pending. Fresh Discord onboarding, manual game relay/power/idle-auto-stop acceptance, Source compatibility, and two-release upgrade/rollback acceptance have not all been completed. Automated tests and isolated container rehearsals do not replace these checks.

One installation supports one Discord guild and one Panel. Satisfactory has no standard chat relay. Game chat is live-only: messages sent during a disconnected interval cannot be recovered. Attachments, message edits, and deletions are not relayed. Source 2 and game-specific plugins need separate compatibility checks. Pelican is not supported by this Egg.

## Existing installations

Back up your complete private data and deployment settings before upgrading. File-configured installations should use `docker-compose.legacy.yml` and the migration instructions. Preserve the existing volume and Compose project name. Schema changes may require the matching pre-upgrade backup when rolling back; do not run an older image against unsupported newer data.

See the README for onboarding, `docs/PTERODACTYL.md` for Egg installation, and `docs/OPERATIONS.md` for backups, updates, migration, and recovery. Report reproducible issues with the release version and redacted diagnostics; never share tokens, `.env`, or private backups.
