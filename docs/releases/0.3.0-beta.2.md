# Bugfix beta: 0.3.0-beta.2

Imported servers now use a valid allocation hostname or IP in their status address. Descriptive allocation aliases such as `Source UDP` no longer appear as the hostname. Previously saved invalid aliases are repaired from the allocation when monitoring starts.

Every imported server's private administration card now includes **Server address**. Set the public hostname/IP and game port here; changes persist across restarts and refresh status messages without restarting the bot. Valid manually configured addresses remain unchanged.

## Upgrade

Back up the complete private data volume and deployment settings. For the public Compose installation, set `BRIDGE_VERSION=0.3.0-beta.2`, pull the image, and recreate the bot while preserving its project name and data volume. Legacy installations should retain their existing Compose files and volume. No storage schema change or reinstall is required.

For Pterodactyl, import the attached version-matched Egg and explicitly select the matching pinned image on the existing server. Preserve its server directory. Actual Panel/Wings acceptance remains pending, as in beta.1.

After upgrading, refresh the administration panels and use **Server address** if the allocation IP differs from the address players use (for example, behind NAT).

## Validation

All 472 automated tests passed for the address fix, including allocation-label fallback, persistent administration edits and invalid-input rejection. Release CI also validates the version and rehearses the packaged Egg image. Existing beta limitations remain; this release does not claim complete live game or Panel/Wings acceptance.
